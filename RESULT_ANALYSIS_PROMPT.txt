====================
指標方向
====================

請依照以下方向解讀：

SSD：越低越好。整體平方誤差，代表 restored ECG 與 clean reference 的差距。
MAD：越低越好。Maximum Absolute Distance，代表最大絕對偏差。
PRD：越低越好。Percent Root-mean-square Difference，代表相對重建誤差。
CosSim：越高越好。波形 cosine similarity，越接近 1 代表越相似。
Output_SNR_dB：越高越好。輸出訊號相對 clean reference 的 SNR。
SNR_Improvement_dB：越高越好。相對 noisy input 的 SNR 改善量。
LF_Reduction_dB：越高越好。低頻 baseline wander 被降低的程度。
R_Peak_Timing_Error_ms：越低越好。R-peak 位置誤差，代表心拍定位是否被破壞。
RR_Interval_MAE_ms：越低越好。RR interval 平均絕對誤差，代表心律間距保留程度。
RMSE：越低越好。Root Mean Squared Error。
Centered_CosSim：越高越好。去除 DC offset 後的 cosine similarity。
QRS_Amplitude_Error：越低越好。QRS 振幅誤差，代表 QRS morphology 是否被保留。

Complexity 指標：
Parameters：越低代表模型較小，但不一定代表效果較好。
Trainable_Parameters：越低代表訓練參數較少。
FLOPs：越低代表計算量較低。
Inference_Time_ms：越低代表推論較快。
Peak_Memory_MB：越低代表記憶體需求較低。

分析要求
====================

請你收到數據後，按照以下順序分析：

1. 先判斷資料集與 checkpoint
說明這份結果是 PTB-XL fold 10、MIT-BIH、Chapman、CPSC、controlled test，還是 complexity。

哪個模型整體最好。

3. 分資料集比較

PTB-XL fold 10 in-domain test。
MIT-BIH external test。

CPSC external test。

如果某些資料集缺失，請明確說「目前沒有提供該資料集結果，不能下結論」。

4. 分指標族群解讀
請不要只逐欄翻譯，要把指標分組：

重建誤差：
SSD、MAD、PRD、RMSE。

波形相似度：
CosSim、Centered_CosSim。

Baseline removal：
SNR_Improvement_dB、LF_Reduction_dB、Output_SNR_dB。

ECG morphology preservation：
R_Peak_Timing_Error_ms、RR_Interval_MAE_ms、QRS_Amplitude_Error。

效率：
Parameters、FLOPs、Inference_Time_ms、Peak_Memory_MB。

5. Robustness 分析
如果我貼 exp2_strength/summary.csv：
請分析不同 alpha values 下模型是否穩定。
alpha 越高代表 baseline wander 越強。
請看 PRD、SNR_Improvement_dB、LF_Reduction_dB、R_Peak_Timing_Error_ms 是否隨強度惡化。

如果我貼 exp3_frequency/summary.csv：
請分析不同 baseline frequency 下模型是否穩定。
請特別注意 0.05 到 0.5 Hz 的低頻 baseline，以及 0.8、1.0 Hz 較接近 ECG morphology 的頻段。

6. 統計檢定
如果我貼 paired-stats CSV：
請解釋 p-value、校正後 p-value、effect size。
請不要只說顯著或不顯著，要說「哪個模型在該指標上比較好」。
如果 p-value 顯著但差異很小，也請提醒 practical significance 可能有限。

7. 圖像解讀
如果我提供 prediction_sample 圖：
請看：
input 是否有 baseline drift。
restored 是否貼近 clean reference。
residual 是否接近 0。

ST/T wave 是否被過度平滑。

如果我提供 spectrum_sample 圖：
請看：
restored 的低頻 PSD 是否比 input 降低。
restored 是否接近 clean reference。
是否有高頻或 QRS 相關頻段被過度削弱。
